# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), v2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment, personal attacks, and off-topic hostility aren't welcome here.

Issues can be reported by opening a GitHub issue or contacting the maintainer directly.
